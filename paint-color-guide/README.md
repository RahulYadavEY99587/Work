# Premium Paint Design Guide — 50 Gaj House

Complete wall-by-wall color specification using **British Paints** shades from your shade card.

## How to view

Open `index.html` in any web browser:

```bash
# From this folder
xdg-open index.html   # Linux
open index.html       # macOS
start index.html      # Windows
```

## Save as PDF

1. Open `index.html` in Chrome or Edge
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Choose **Save as PDF**
4. Give it to your painter

## What's included

- Master color palette (15 shades with exact codes)
- House floor plan color map (SVG)
- Room-by-room wall specifications with 3D diagrams
- Living room, bedroom, kitchen, bathroom, gate area details
- Visual mockup previews
- Complete shopping list with quantities
- Luxury finish rules
